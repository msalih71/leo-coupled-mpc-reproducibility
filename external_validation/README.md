# External Swarm/JB2008 comparison for TAES-2026-0295

Run scripts from this `external_validation/` directory, with the adjacent `code/` and `data/` directories adjacent one level above. Install the Python dependencies listed in the parent README plus `pandas` and `requests`; install `gfortran` for JB2008. The eight derived CSV files in this directory are included for offline numerical comparison without any network request.

1. Run `python observed_comparison.py` to download ESA VirES HAPI Swarm POD records and generate `observed_results/*_aligned.csv` plus the TIM/NRLMSISE comparison. `python observed_acc_comparison.py` retrieves the accelerometer-product cross-check. Follow the ESA data terms and cite the products.
2. Obtain the *unmodified* `JB2008.for.txt`, `JB08DRVY2K.for.txt`, `SOLFSMY.TXT` and `DTCFILE.TXT` directly from Space Environment Technologies at https://spacewx.com/jb2008/ . Save them within the local `jb_sources/` directory, renaming the `.for.txt` files to `.for`. Do not add vendor code/indices to a redistributed package. Compile `gfortran -O2 -ffixed-line-length-none jb_sources/JB2008.for jb_call.f90 -o jb_sources/jb_call.exe`.
3. Run `python jb_compare.py` to regenerate the POD 5-minute table and `python jb_compare.py --acc` for the ACC table. `python verify_jb_driver.py` checks the calling wrapper against SET's unmodified driver after compiling `gfortran -O2 -ffixed-line-length-none jb_sources/JB08DRVY2K.for jb_sources/JB2008.for -o jb_sources/JB08DRV.exe`.
4. Run `python observed_block_bootstrap.py` for paired 90-minute-block intervals; `python observed_causal_forecast.py` for the retrospective causal-input TIM forecasting check (historical previous-day F10.7); `python reference_altitude_sensitivity.py` to compare both TIM coefficient sets against JB2008 after a 24-hour within-event warm-up; `python observed_residual_replay.py` for the explicitly out-of-orbit density-residual forcing test. The last test uses three measurement-noise seeds; its result is a sensitivity study, not an observed Swarm flight replay. The altitude sensitivity script requires the locally downloaded `observed_results/*_aligned.csv` and corresponding `*_aligned_5min_JB.csv` files from steps 1–3.

The supplied CSVs capture the ESA data and SET historical indices available on 24 September 2026. The closed-loop tables in this package were regenerated from ten noise seeds after correcting the complete weather-index ablation and the 72-h fuel-accounting window. The original SET Fortran driver has fixed-size index arrays; `verify_jb_driver.py` uses short temporary subsets of the downloaded index data without editing the vendor code. The standalone official SET validation ZIP was unavailable; the three dated driver cross-checks are documented in the manuscript supplement.
